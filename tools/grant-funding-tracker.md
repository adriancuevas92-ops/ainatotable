# Reading Grant Deadlines Correctly

If you're building a food forest or a land-restoration project in Hawaiʻi, real
funding exists for it — but a posted deadline on Grants.gov often isn't the
whole story. Below is a live-updating list of real programs relevant to that
kind of work, with the specific thing to check on each one before you assume
it fits or trust the date shown.

## Why this exists

A grant program's Grants.gov listing shows a submission deadline. It doesn't
always show whether that deadline applies to you specifically, whether the
program even accepts a direct application from an organization like yours, or
whether this year's actual funding priority still matches the program's name.
Finding that out took a real, avoidable near-miss: almost writing a full
application against a posted deadline that turned out to be for applicants
already invited into the process — the real cutoff for a first-time contact
had already passed, because the program requires reaching out to program
staff before any application exists at all.

That mistake is common enough, and costly enough in wasted effort, that it's
worth writing down plainly rather than keeping it to ourselves.

## What to check on any program, not just these

- **Who can actually apply.** Some programs fund a state agency directly, and
  a nonprofit or small organization can only participate as a named partner
  on that agency's own application — not as a solo applicant.
- **Whether the process is contact-first.** Some programs require reaching
  out to program staff before an application exists at all — the posted
  "deadline" may only apply to applicants already in that conversation.
- **Whether this year's specific funding priority still matches the
  program's name.** A program can keep the same name and general authorizing
  purpose year to year while its actual funding priority shifts.
- **Whether a shared program number actually means the same program.**
  Federal assistance-listing numbers are sometimes shared by more than one
  real, separately-run funding notice — read the specific one you're looking
  at.

## A note on how this list works

This isn't every program that might apply, and it isn't updated in real time
against Grants.gov itself — the *dates* recalculate live in your browser, but
the underlying facts (who's eligible, what a program actually funds) are
checked by hand and only as current as the "checked" date on each card. It's
a short, honestly-checked list, the same standard the rest of this site holds
to. Know of a program that belongs here, or see something that's gone stale?
